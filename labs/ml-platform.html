DDP · W2

Why zero_grad() every step?

Three training steps. Each backward() produces a fresh gradient — watch what lands in .grad.

Press Next step.

So what: backward() adds (+=) into .grad. Without clearing, step 3 updates with g1+g2+g3 instead of g3 — the wrong direction and too big a step. (Gradient accumulation uses this on purpose: skip zero_grad for N micro-batches, then step once.)

DDP · W2

What does set_epoch change — and why don't ranks overlap?

8 samples, 2 ranks, shuffle=True. Each rank shuffles the full index list with a seed, then takes every 2nd position.

So what: ranks never overlap because they all use the same seed, so they shuffle into the same order and split it. set_epoch makes that seed new each epoch, so the order changes from epoch to epoch.
